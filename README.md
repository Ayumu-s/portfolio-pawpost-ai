# PawPost AI

写真・複数写真・動画を入力し、プロフィールや当日の情報を反映したInstagram向け投稿案を作成し、編集・プレビューするMVPです。

> 公開用の決定的なMockモードを実装済みです。APIキーなしで、投稿案の生成・編集・プレビュー導線を確認できます。

## 重要な範囲

このプロジェクトは「投稿案の生成とプレビュー」を扱います。Instagramへのログイン、実投稿、予約投稿、アカウント管理は実装対象ではありません。

## デモの状態

- Mockモード: デフォルト。外部AIへ接続せず、架空の解析結果と投稿案を返す
- 公開版のデモ: APIキーなし、架空の入力データで実行

Mockモードの画像解析結果は、実画像を解析したものではないことを明示した固定データです。画面には「デモモード・外部AI未接続」と表示し、実サービスの応答と区別します。

## 主な機能

- 画像、複数画像、動画の入力
- 投稿カテゴリ・テンプレートの選択
- AI投稿案の生成、再生成、手動編集
- Instagram風プレビュー
- 投稿テンプレートの保存
- Mockプロバイダーの使用状態表示

## アーキテクチャ

- `frontend/`: Next.jsによる入力・編集・プレビュー画面
- `backend/`: FastAPIによるメディア処理、テンプレート管理、AIプロバイダー境界
- `scripts/`: ローカル起動と確認用スクリプト

## 起動方法

### Mockモード

```powershell
.\scripts\setup.ps1
```

セットアップ後、別々のPowerShellで起動します。

```powershell
.\scripts\run-backend.ps1
.\scripts\run-frontend.ps1
```

`http://localhost:3000` を開き、画像または動画を入力して投稿案を生成します。初期プロバイダーは画像・文章ともに `mock` です。バックエンドのMockProviderはネットワークやAI SDKを呼び出しません。

## テストと確認範囲

バックエンドの `pytest` でMock設定のAPI経路、メディア処理、テンプレート保存を確認できます。フロントエンドの型チェック・ビルドとブラウザ上の主要導線は、依存パッケージをセットアップした環境で別途確認します。実AIの品質とInstagram実投稿は対象外です。

## 未実装・制約

- Mockの画像解析は実画像の内容を認識せず、固定のデモ説明を返す
- Instagramへの実投稿・予約投稿・ログインは行わない
- 動画や複数画像の処理はサイズ・枚数などの制限がある
- Mock結果は実画像の内容や実AIの品質比較を目的としない

## セキュリティとサンプルデータ

APIキー、認証情報、実アカウント情報、個人の画像やログをリポジトリへ含めません。公開版では架空のプロフィール・入力データを使用します。MockProviderはネットワークやAI SDKを呼び出しません。
